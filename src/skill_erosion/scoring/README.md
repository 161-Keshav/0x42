# Scoring work area

Add `features.py`, `matching.py`, and `ensemble.py` here during Phase 2.
Use correctness, duration, hint usage, and similarity to prior work. Keep feature
values and model version auditable. Match student, skill, checkpoint, task set,
and rubric before computing a gap. A raw correctness difference in a synthetic
fixture is an expected trend example, not the finished ensemble model.

Train/calibrate only on a defined training split; hold out students for evaluation.
Do not train and report accuracy on the same seeded examples. Require at least
three paired checkpoints; preserve contradictory and insufficient-evidence states.
